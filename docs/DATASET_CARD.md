# Dataset card — MAI-13 prompt/continuation benchmark (text)

## Summary
Pairs of **(prompt, human continuation)** drawn from C4 `realnewslike`, plus AI continuations generated
by MAI-13 from the same prompts (unwatermarked and watermarked), plus attacked variants. Only the
source records are a "dataset" in the usual sense; everything else is regenerated deterministically
from the experiment config and seed.

| Field | Value |
|---|---|
| Source | `allenai/c4`, config `realnewslike`, split `validation` (streamed) |
| Licence | ODC-BY 1.0 for C4; underlying pages subject to Common Crawl terms of use |
| Collection date of source | Common Crawl, April 2019 |
| Unit | One web document → prompt = first *P* words, human continuation = next *C* words (slice of the original string, formatting preserved) |
| Default sizes | `main_benchmark`: 300 documents, P=50, C=150 |
| Languages | English (C4 is language-filtered with langdetect ≥ 0.99) |
| Versioning | `records.jsonl` SHA-256 + split seed + split fractions → `dataset_versions.version`; manifest JSON stored next to the records and referenced from the DB |

## Labels and their justification
| Kind | Label | Justification (`label_source`) |
|---|---|---|
| Human continuation | `human` | C4 realnewslike original text, crawled April 2019 — before widespread LLM-generated web text. **Not guaranteed**: spam, templated and machine-translated pages exist in C4. |
| Unwatermarked AI continuation | `ai` | Generated by the configured model in the named experiment (by construction). |
| Watermarked AI continuation | `ai` | Same, with the named watermark. |
| Attacked text | inherits parent label | Documented as inherited via the named transformation. Note: heavy paraphrase by an LLM makes "human" children partly machine-written; results on attacked human text measure **false-positive behaviour**, not authorship. |

## Splits
- Assigned **per source document** by `sha256(seed:group_id)` → 60/20/20 train/val/test by default.
- Every derived text (AI, watermarked, attacked) inherits its document's split.
- Classifiers train on train, thresholds are chosen on val, all reported metrics are on test.

## Leakage controls
1. Build time: exact (normalised hash) and near-duplicate (MinHash/LSH over word 5-grams, Jaccard ≥ 0.8)
   checks across splits on prompts and human continuations.
2. After generation: the same audit across *all* texts, plus a check that no document group spans splits.
Both results are in the manifest / `results.json` and the report.

## Known limitations and biases
- Single domain (news-like web text, 2019) and single language.
- Length is controlled (C words vs. max_new_tokens tokens) but not identical; a classifier may exploit
  residual length or formatting differences (e.g., C4 newlines vs. model outputs).
- Prompts are truncated mid-sentence at a word boundary, which is the Kirchenbauer et al. protocol but
  differs from instruction-style use.
- C4 contains offensive and personal content at low rates; nothing is filtered beyond C4's own filters.

## Local / custom datasets
`dataset.source: jsonl` accepts one JSON object per line with **required** `text`, `source`, `license`,
`label_source` (and optional `id`, `url`). Records missing any provenance field are rejected.
